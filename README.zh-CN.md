# Smart Actions

用 **Jev** 根据表格内容进行分类、判断紧急程度或评分，并将结果写回你的 `.eidos` 文件。

[English](README.md)

**选择输入 → 定义判断规则 → 指定输出字段。**

一个动作可以读取多个字段、写入多个结果。你可以手动配置，也可以描述需求，让 AI 生成可供检查和修改的草稿。

## 可以做什么

| 输入 | 判断 | 输出 |
| --- | --- | --- |
| 客户消息 | 应交给哪个部门处理？ | Category · 单选字段 |
| 消息与标题 | 是否需要立即处理？ | Urgency · 0–1 概率 |
| 客户反馈 | 客户有多不满意？ | Score · 数值评分 |
| 客户消息 | 是否明确提出退款请求？ | Refund requested · 复选框 |

动作使用 Jev 完成分类、评分和概率判断，不用于生成回复、摘要等自由文本，也不会创建记录或新增字段。

## 使用前准备

Smart Actions 要求插件 API **1.1.0**，安装包使用格式 2，旧客户端需要先升级。
CLI Serve 尚不支持所需的动作和配置接口。插件 API 契约版本与 npm SDK 版本独立。

- **Eidos Lite 0.17.0 或更新版本**，支持插件 API 1.1.0。
- 用于访问 Jev 的 TypeSafe AI API Key。
- 一个已有数据表及所需输入、输出字段的 `.eidos` 文件。

如果希望用自然语言生成动作，再配置一个生成模型；手动创建不需要这个额外连接。

## 安装与连接

1. 将 `.eidos-plugin` 安装包拖入 Lite 的 **Plugins** 页面，并为当前 Space 启用。更新时，将新版安装包拖入同一页面即可。
2. 打开 **Plugins → Smart Actions → Settings → TypeSafe AI**，保存 API Key。
3. 右键 `.eidos` 文件，选择 **Open with → Smart Actions**。

## 创建动作

在左侧选择数据表，点击其动作列表旁的 **＋ 新建动作 → 手动创建**。

1. **输入字段**：勾选需要读取的字段。
2. **输出字段**：添加输出，指定一个已有的可写字段。
3. **判断规则**：点击流程图中的输出，在下方设置判断类型和规则。例如：「根据 Message 字段中的客户消息，选择最符合主要诉求的部门。」
4. 为动作命名、选择图标，然后点击 **保存**。

左侧按数据表组织动作。拖动侧栏右边界可调整宽度，双击恢复默认宽度。编辑器保持打开时，切换表或输出会保留未保存的修改。

### 用 AI 生成草稿

先在 **Plugins → Smart Actions → Settings → Action Generator** 配置：

- 完整的公网 HTTPS Chat Completions 地址，包含 `/v1/chat/completions`。
- 服务商提供的模型名称。
- 该地址对应的 API Key。

选择 **＋ 新建动作 → 用 AI 生成动作**，描述需求并生成草稿。例如：

> 根据客户消息分类，复用 Category 的现有选项；把需要立即处理的概率写入 Urgency。

检查草稿的输入、输出和判断规则，修改后保存。生成草稿不会执行动作或修改记录。生成模型负责设计配置，实际运行仍由 Jev 完成判断。

## 执行、停止与撤销

用内置编辑器打开文件，在 Grid 中右键单条记录或选中的记录，选择对应动作。**全选**也包含当前筛选结果中尚未加载到界面的记录。

通过校验的结果会直接写入。任务窗口显示进度和 Jev 执行的预估费用。停止任务后，已完成的写入会保留。

- **撤销本次操作**：恢复本次已完成的写入，不覆盖之后发生的编辑。
- **重做本次操作**：重新应用已保存的结果，不再次调用模型。
- 撤销仅在当前表和任务会话中可用，重启 Lite 后不可继续撤销该任务。
- 关闭任务窗口只是隐藏窗口；需要停止处理时，请使用停止操作。

任务开始时会固定目标记录。之后修改筛选条件或新增记录，不会改变本次处理范围。已删除的记录会跳过；错误或写入冲突会停止处理，之前完成的写入仍然保留。

## 输出类型

| 判断类型 | 写入字段 | 行为 |
| --- | --- | --- |
| 分类 | 单选 | 复用字段的当前选项，在字段设置中维护。 |
| 分类 | 文本 | 从动作中配置的候选类别里选择。 |
| 评分 | 数字 | 按有序等级评分，从 0 开始，结果可以是小数。 |
| 概率 | 数字 | 写入 0–1 之间的概率值。 |
| 是 / 否 | 复选框 | 按配置的概率阈值决定是否勾选。 |

分类需要 2–255 个不重复的非空选项，评分需要 2–10 个有序等级。各输出独立读取输入进行判断，不能依赖同次执行中其他输出的结果。

## 数据与连接

动作配置随数据表保存在 `.eidos` 文件中。API Key 由 Lite 单独加密保存，连接配置属于当前 Space，不写入数据文件。更换生成模型的接口地址后，需要重新输入密钥。

| 操作 | 发送给服务商的内容 |
| --- | --- |
| 生成草稿 | 你的需求、表的字段结构和选项；不发送记录内容。 |
| 执行动作 | 选中的输入字段值，以及判断规则和候选选项。 |
| 撤销或重做 | 不调用模型。 |

执行时每个请求最多处理 10 条记录，同时进行两个批次；输入较大时会拆成更小的批次。显示费用根据返回的用量估算，不是最终账单；缺失用量不会按免费计算。生成草稿的模型费用单独计费，撤销不会退还已产生的费用。

## 常见问题

- **无法生成草稿**：先配置 Action Generator，检查完整接口地址、模型名称和密钥。
- **找不到合适的输出字段**：先用内置编辑器创建字段，Smart Actions 只写入已有字段。
- **分类缺少选项**：在单选字段的设置中补充，每次执行都会读取最新选项。
- **只更新了一部分记录就停止**：检查任务错误并解决原因，或先撤销已完成的写入，再重新运行。

## 开发

源码与对应测试放在 `src/` 中，`plugin.json` 声明扩展和配置界面的入口。
构建与冒烟测试脚本放在 `scripts/` 中。

```sh
npm ci
npm run check
npm test
npm run pack:plugin
```

安装包与校验文件生成在 `dist/`，插件没有运行时依赖。配置保存在 `settings_json.plugins["eidos.smart-actions"]`。单次任务最多处理 100,000 条记录，并受宿主 64 MiB 撤销存储上限约束。

`scripts/live-smoke.mjs` 可从 `TYPESAFE_API_KEY` 或标准输入读取密钥，使用合成数据测试。不要提交凭据。

[Jev API 文档](https://docs.typesafe.ai/api)
